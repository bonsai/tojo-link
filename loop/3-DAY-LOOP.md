# 🔄 3日ループ — アイデア → 実行 → 改善

> 「3日で1回転。迷わない。止まらない。」

---

## 📅 全体像

```
Day 1: アイデア → POC
Day 2: リサーチ → 制作 → 投稿
Day 3: アナリティクス → 分析 → 改善 → 次のアイデア
```

**毎週2回転。月8回転。年96回転。**

## 🕐 午後（1時間）: 分析 → 改善 → 次のアイデア

### 分析フレームワーク

```
結果を見る → 仮説を立て → 次のアクションを決める
```

### 診断マトリクス

|  | 再生数 高 | 再生数 低 |
|--|----------|----------|
| **維持率 高** | ✅ 勝ちパターン<br>→ 同じ形式で量産 | 💡 改善余地あり<br>→ サムネ・タイトル改善 |
| **維持率 低** | ⚠️ 釣り注意<br>→ 内容は良いが期待はずれ | ❌ 要検討<br>→ テーマ or 形式変更 |

### 改善アクションリスト

| 課題 | 改善策 |
|------|--------|
| 最初の3秒で離脱 | オープニングのインパクト強化 |
| 中だるみ | カット割りを細かく（3秒以内） |
| CTR低い | サムネの文字大きく・色変更 |
| 高評価率低い | エンディングの呼びかけ変更 |
| 投票数少ない | 動画内リンク目立たせる |

### 次のアイデア決定

```
今回の結果
  ↓
良かった要素 × 3 = 次のテーマ
悪かった要素 → 除外 or 改善
  ↓
Day 1のアイデア出しに反映
```

## 🔄 3日ループ スケジュール

```
Week 1
├── Day 1 (月): アイデア → POC
├── Day 2 (火): リサーチ → 制作 → 投稿
├── Day 3 (水): 分析 → 改善 → 次アイデア
├── Day 4 (木): アイデア → POC
├── Day 5 (金): リサーチ → 制作 → 投稿
├── Day 6 (土): 分析 → 改善 → 次アイデア
└── Day 7 (日): 予備 / 改善 / 来週準備

Week 2以降も同じリズム
```

## 🎯 最重要: 止めないこと

```
完璧な動画より、毎日投稿する動画
↓
毎日投稿する動画より、3日で1回転する仕組み
↓
3日で1回転する仕組みより、改善を続ける習慣
```

**3日ループを10回回せば、自ずと勝ちパターンが見つかる。**
