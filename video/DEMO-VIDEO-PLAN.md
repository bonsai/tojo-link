# 🎬 Demo Video Plan — 東上リンク

## 概要
**「ぷるぷる駅ピッカー × カスタム3件推薦 × リンク保存」** のUI体験を30秒で伝えるデモ動画

---

## 📱 収録構成（合計 約45秒）

| # | シーン | 時間 | 見せる操作 | 強調ポイント |
|---|--------|------|-----------|-------------|
| 1 | **オープニング** | 5s | トップページ表示 | 「あなたへのおすすめ」3件がファーストビュー |
| 2 | **駅ピッカー** | 10s | ハンドルタップ→展開→駅選択 | ぷるぷるアニメーション + ⭐推薦マーク |
| 3 | **フィルター** | 5s | 駅チップタップ→ボード切替 | スムーズなフィルター |
| 4 | **カード操作** | 10s | リンクプレビュータップ → 「行ってみたい」保存 | バイブレーション + ✓ フィードバック |
| 5 | **共通ユーザー** | 5s | 「共通12人」表示 | ゆるいつながり感 |
| 6 | **投稿フロー** | 10s | ＋ボタン→フォームスライド→入力→投稿 | 24h制限表示 + トースト通知 |

---

## 🎥 撮影方法

### Option A: ブラウザ録画（推奨・無料）
```bash
# Chrome DevTools > Device Mode (iPhone 12/14)
# 画面記録: QuickTime (Mac) / Xbox Game Bar (Win: Win+G)
# または: OBS Studio (免费)
```

### Option B: シミュレーター
```bash
# Xcode Simulator (Mac)
xcrun simctl recordVideo demo.mp4

# Android Emulator
emulator -record-video demo.mp4
```

### Option C: 実機
```bash
# iOS: 設定 > コントロールセンター > 画面収録
# Android: クイック設定 > 画面記録
```

## 🚀 デモ起動方法

```bash
# 1. リポジトリに移動
cd tojo-link-board

# 2. ローカルサーバー起動
npx serve demo -l 3001

# 3. ブラウザで開く
# モバイル: http://{ローカルIP}:3001
# デスクトップ: http://localhost:3001

# 4. Chrome DevTools > Device Mode でスマホ表示
```
