# 🧭 改善の方向性 — 3つの視点と目的の整理

---

## ❓ 今、問い直すべきこと

Demo v2は「見た目」がよくなった。
でも **「誰の・何を・解決するのか」** がまだ曖昧。

見た目より先に、**目的の解像度** を上げるべき。

---

## 📐 視点1: 「ユーザー」視点 — 誰のために？

### 現状のペルソナ問題
| 課題 | 詳細 |
|------|------|
| 美恵子(52歳) | スマホ苦手だが興味あり → **でも「リンクを投稿」するハードルは高い** |
| 健一(28歳) | UXにうるさい → **でも既存のInstagram/Threadsで十分では？** |
| 共通の問題 | **「なぜ、このサービスを使うのか？」が弱い** |

### 問い直し
> 「カメラ＋駅名だけ」→ リンク投稿に変わったが、
> **「ユーザーは何を得たいのか？」** が不明確

### 考えられるユーザー目的

| ユーザータイプ | やりたいこと | 使う動機 |
|---------------|-------------|---------|
| **沿線住民** | 「いいお店」を教えたい/知りたい | 地域愛着、発見の喜び |
| **カフェ好き** | 隠れ家カフェを見つけた・教えたい | 共有欲、承認欲求 |
| **イベント主催者** | 参加者を集めたい | 無料の募集手段 |
| **鉄道ファン** | 駅の風景・記録を残したい | アーカイブ欲求 |
| **商店主** | お店の存在を知ってもらいたい | 無料PR、集客 |

### 🔍 改善の方向性A: **「発見」に特化**
```
目的: 「沿線の良いものを、近くの人と共有する」
機能: リンク投稿 + 行ってみたい保存 + 共通ユーザー表示
メトリクス: 月間保存数、再訪問率
```

### 🔍 改善の方向性B: **「募集」に特化**
```
目的: 「駅ごとに、人と人をつなぐ」
機能: イベント投稿 + 参加表明 + DM（簡易）
メトリクス: 月間マッチング数
```

### 🔍 改善の方向性C: **「記録」に特化**
```
目的: 「駅の記憶を、AIでアーカイブする」
機能: 写真投稿 → AIタグ → 時系列ストック → 静的ジン
メトリクス: 月間投稿数、AIタグ精度
```

## 📐 視点2: 「ビジネス」視点 — 誰がお金を払う？

### 現状
- Firebase/Supabase: 月$25
- AI処理: 月$5-10
- 合計: **月¥4,500程度**

### 収益化の候補

| モデル | 概要 | 現実性 |
|--------|------|--------|
| **広告** | 沿線店舗のバナー掲載 | ◎ 小規模でも可能 |
| **有料掲載** | 「おすすめ」表示で課金 | △ 信頼性とトレードオフ |
| **データ販売** | 沿線トレンド分析レポート | ○ BtoBなら可能性 |
| **プレミアム機能** | 保存数無制限・早期通知等 | △ ユーザー獲得後 |
| **自治体連携** | 地域活性化ツールとして提供 | ○ 公的資金の可能性 |

### 🔍 改善の方向性D: **「商店主向けPRプラットフォーム」**
```
目的: 沿線店舗の無料PR + 有料オプション
顧客: 商店主（BtoB）
ユーザー: 沿線住民（BtoC、無料）
収益: 有料掲載（月¥3,000-10,000/店舗）
必要なもの: 店舗管理画面、アクセス解析、レポート機能
```

## 🎯 目的の整理マトリクス

| 視点 | 目的 | 優先度 | 検証コスト |
|------|------|--------|-----------|
| A: 発見 | 沿線の良いものを共有 | ★★★★ | 低（既存UIで可能） |
| B: 募集 | 人と人をつなぐ | ★★ | 中（DM機能必要） |
| C: 記録 | 駅の記憶をAIアーカイブ | ★★★ | 高（AI処理必要） |
| D: 商店PR | 店舗の無料PRプラットフォーム | ★★★★ | 中（店舗管理画面） |
| E: 技術検証 | スタックの実証 | ★★★★★ | 低（1週間） |

## 💡 推奨: 段階的アプローチ

```
Phase 1（今すぐ）: 技術検証MVP
  → 駅選択 + リンク投稿 + Firebase表示
  → 目的: 「動くこと」を実証

Phase 2（1ヶ月後）: 発見プラットフォーム
  → 保存機能 + おすすめ表示 + 共通ユーザー
  → 目的: ユーザー獲得・反応計測

Phase 3（3ヶ月後）: 商店主向け機能
  → 店舗登録 + アクセス解析 + 有料オプション
  → 目的: 収益化の検証

Phase 4（6ヶ月後）: AIストック
  → AIタグ + 静的ジン生成 + アーカイブ
  → 目的: 独自価値の確立
```
