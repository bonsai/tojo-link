# 🔥 東上リンク — ビジネス戦略 v4

## 🎯 核心: 押さえるべき「3つの資産」

```
1位: 「やばい店ランキング」というブランド
     → 権威。他社が真似できない。「あそこのランキング」って言わせたい

2位: 発掘者（投稿者）のコミュニティ
     → ネットワーク。投稿者が増えるほどデータが増える

3位: 駅ごとのトラフィックデータ
     → 数字。店舗・自治体・広告主にとって価値がある
```

**これの順番。逆は絶対にダメ。**
データより前にブランド。ブランドより前に投稿者。

## 🔄 永続コンテストの仕組み

### 構造

```
各駅に「やばい店ランキング」（常時更新）
  ├── 暫定1位〜5位 = 「殿堂入り」
  ├── 6位〜20位 = 「ランクイン候補」
  └── 21位以下 = 「発掘待ち」

新しい投稿 → 自動でランキングに追加 → 投票で変動 → 暫定発表
```

### 投稿者の「うまみ」構造

| 行動 | うまみ |
|------|--------|
| 新店を発掘して投稿 | ランキング初登場 = 「俺が見つけた」感 |
| ランクインすると | 通知 → 承認欲求充足 |
| Top5入りすると | 投稿者名が発表ページに永久掲載 |
| テキスト動画を投稿 | 「発掘レポート」として共有 |
| 何度もランクイン | 「名発掘者」バッジ |

### 見る人の「うまみ」構造

| 行動 | うまみ |
|------|--------|
| 暫定順位を見る | 「今はどこが一位？」→ 定期訪問 |
| 投票する | 「推し店を上げたい」→ 参加感 |
| ランキング変動 | 「昨日と違う！」→ ドキドキ |
| 発掘テキスト/動画 | 「どんな店？」→ 発見の喜び |

## 📊 ランキング更新の仕組み

### 自動集計（リアルタイム）

```
投票数 × 1.0
+ 新規ボーナス（投稿から48時間以内）× 0.5
+ 発掘者信頼度スコア × 0.3
+ 直近24時間の投票 × 1.5（トレンド補正）
= 暫定スコア
```

### 発表リズム

| 発表 | 頻度 | 方法 | 内容 |
|------|------|------|------|
| **リアルタイム更新** | 常時 | Webページ | 全駅・全店舗の順位 |
| **デイリー速報** | 毎日12時 | Threads | Top3変動のお知らせ |
| **ウィークリー確定** | 毎週日曜 | Web + Threads | 「今週の結果」 |
| **マンスリー殿堂** | 毎月1日 | Web + PDF | 「月間Top5」発行 |
| **イヤーベスト** | 毎年 | イベント | 「年間やばい店大賞」 |

### 暫定順位の「演出」

```
🚃 鶴瀬駅 やばい店ランキング
━━━━━━━━━━━━━━━━━━━━━━
  1位 🥇 麹カフェつるせ    142票 ▲3
  2位 🥈 パン屋はなまる     138票 ▼1
  3位 🥉 レコード喫茶小江戸  120票 →
  4位    蕎麦処やまぐち      98票 ▲2
  5位    居酒屋たかはし      85票 ▼2
━━━━━━━━━━━━━━━━━━━━━━
  発掘: 23件 / 投票: 891人 / 更新: 10分前
```

**「▲3」「▼1」が中毒性を生む。**

## 🗺️ マイナー路線のみでやる理由

### 戦略的優位性

| 項目 | メジャー路線 | マイナー路線 |
|------|-------------|-------------|
| 競合 | 多数（食べログ、Retty等） | **ほぼゼロ** |
| 店舗の認知度 | 既に高い | **低め → 効果が実感できる** |
| 自治体の関心 | 低い（既に観光客多い） | **高い（誘致したい）** |
| ユーザーの熱量 | 薄い | **濃い（地元愛）** |
| 参入難易度 | 高い | **低い** |

### ターゲット路線

```
優先度高（マイナー・沿線愛強い）
├── 東武東上線 ★今回のターゲット
├── 東武伊勢崎線（日光線）
├── 西武秩父線
├── 小湊鐵道
├── 真岡鐵道
└── 銚子電鉄

優先度中（少しメジャーだがまだ余地あり）
├── 西武池袋線
├── 京王線
├── 小田急線
└── 東急東横線

優先度低（競合多すぎ）
├── JR山手線
├── 東京メトロ
└── 東急田園都市線
```

### ① 広告（Phase 2: 月間1,000ユーザーから）

**仕組み**: ランキングページの「4位の下」にバナー

```
  1位 🥇 麹カフェつるせ
  2位 🥈 パン屋はなまる
  3位 🥉 レコード喫茶小江戸
  4位    蕎麦処やまぐち
  ━━━━━━━━━━━━━━━━━━━
  【PR】 鶴瀬駅徒歩3分の新しいカフェ →
  （関連店: 麹カフェの隣にバナー）
  ━━━━━━━━━━━━━━━━━━━
  5位    居酒屋たかはし
```

**単価**: ¥3,000-5,000/月/店舗
**利点**: 既存ランキングの隣なので邪魔じゃない
**欠点**: 小規模では収益低い

---

### ② 店舗有料プラン（Phase 3: ランキングに載った店から）

**仕組み**: Top10入りした店舗に「店舗ページ」をオファー

```
無料プラン（自動）
├── ランキング掲載
├── 基本情報表示
└── 投票数表示

有料プラン（¥3,000/月）
├── 無料プラン +
├── 写真3枚掲載
├── メニュー掲載
├── 「店主の一言」掲載
├── アクセス解析レポート月次
└── SNS用「ランクイン」バッジ提供
```

**店舗側のメリット**:
- 「東上線やばい店ランキング3位」= 無料PR
- アクセス解析 = 「どこから来てるか」が見える
- SNSバッジ = 「あのランキングの3位です」= 集客

**現実性**: Top10入りの店舗は「載った」実感が強い → 有料化しやすい

## 🎯 最も抑えるべきは「② 店舗有料プラン」

### 理由

| 理由 | 詳細 |
|------|------|
| 必然性 | Top10入りの店舗は「嬉しい」→ 有料化の心理的ハードル低い |
| 単価 | ¥3,000/月は店舗にとって安い（広告1日分） |
| 継続 | 月額サブスクリプション = 安定収益 |
| スケール | 1路線30駅 × Top10 = 300店舗 × 10% = 30店舗 × ¥3,000 = ¥90,000/月 |
| 一人運用 | 自動レポート + テンプレメールで対応可能 |

### 計算

```
東上線: 30駅 × Top10 = 300店舗
  → 有料化率 10% = 30店舗 × ¥3,000 = ¥90,000/月

3路線展開:
  → 90店舗 × ¥3,000 = ¥270,000/月

5路線展開:
  → 150店舗 × ¥3,000 = ¥450,000/月
```

**月¥10万なら、一人運用で十分現実的。**
