# 🔥 東上リンク — 戦略 v6

> 「先にバズらせる。ユーザーは後から付いてくる。」

---

## ❌ 前の戦略の問題点

```
「ユーザーが投稿する」
  → でも誰も知らないから投稿しない
  → 投稿がないから誰も見ない
  → コールドスタート問題
```

**誰もいないパーティーには誰も来ない。**

---

## ✅ 新しい戦略: コンテンツファースト

```
運営がリサーチ → 動画作る → バズらせる
  ↓
「このランキング何？」→ 人が集まる
  ↓
「行きたい」を押すだけ → 簡単参加
  ↓
「俺も投稿したい」→ ユーザー投稿が始まる
  ↓
ループ完成
```

**パーティーを自分で盛り上げてから、人を呼ぶ。**

## 🎬 第一步: 動画でバズらせる

### 動画コンセプト

```
「東上線 鶴瀬駅 やばい店 Top5」
  - 60秒の縦動画（Shorts/Reels/Threads）
  - ポップなデザイン
  - テンポ良いナレーション
  - 最後は「投票リンク」で締める
```

### 動画フロー

```
0:00-0:03  「鶴瀬駅、やばい店ランキング発表！」
0:03-0:10  5位: パン屋はなまる（外観+メニュー）
0:10-0:20  4位: 蕎麦処やまぐち（店主のこだわり）
0:20-0:30  3位: 居酒屋たかはし（名物料理）
0:30-0:45  2位: レコード喫茶小江戸（雰囲気）
0:45-0:55  1位: 麹カフェつるせ（絶品メニュー）
0:55-1:00  「投票はこちら → リンク」
```

### 制作コスト（1本あたり）

| 項目 | 時間 | 方法 |
|------|------|------|
| リサーチ | 30分 | WEB + Google + SNS |
| 台本 | 15分 | AI補助 |
| 編集 | 60分 | CapCutテンプレ |
| 投稿 | 5分 | 複数プラットフォーム |
| **合計** | **110分/本** | |

## 🔄 ループ設計

### フェーズ1: 運営発信（1-2ヶ月）

```
運営: リサーチ → 動画 → 投稿（毎日）
ユーザー: 見る → 投票（受動的）
コンテンツ: 順位変動 → 次回動画のネタ
```

**このフェーズで重要なのは「毎日更新」。**
アルゴリズムが回って、おすすめに乗り始める。

### フェーズ2: ユーザー参加（2-4ヶ月）

```
運営: 動画 + 暫定発表
ユーザー: 投票 + 「この店も！」投稿
コンテンツ: ユーザー投稿もランキングに追加
```

**「俺も載せたい」が自然に生まれる瞬間を狙う。**

### フェーズ3: 広告収入（4-6ヶ月）

```
運営: 動画 + ランキング + 広告募集
広告主: セルフサービスで申込
ユーザー: 広告も「行きたい」で反応
```

### 動画パターンの使い回し

```
1. 「◯◯駅 Top5 初発表」→ 基本形
2. 「順位変動！」→ 既存ランキングの更新
3. 「A駅 vs B駅」→ 比較系
4. 「ジャンル別 Top3」→ カフェ/居酒屋/雑貨
5. 「ユーザー発掘特集」→ 投稿ピックアップ
```

**5パターンを回すだけで1ヶ月持つ。**

## 🛠️ 制作体制（一人）

### 1日の作業（2時間）

| 時間 | やること |
|------|---------|
| 30分 | WEBリサーチ（新店・話題） |
| 30分 | 台本作成（AI補助） |
| 40分 | 動画編集（CapCutテンプレ） |
| 20分 | 投稿（複数プラットフォーム） |

### 効率化ツール

| タスク | ツール |
|--------|-------|
| リサーチ | Google Alerts, RSSリーダー |
| 台本 | ChatGPT/Claude |
| 動画編集 | CapCut（テンプレ保存） |
| 投稿管理 | Buffer/Hootsuite |
| 分析 | YouTube Studio, Threads Insights |

### CapCutテンプレート化

```
1. オープニング（3秒）→ 固定
2. 5位→1位 カード表示（各10秒）→ テンプレ
3. エンディング「投票して」（5秒）→ 固定
4. BGM → 固定（著作権フリー）
5. フォント・色 → 固定

→ 中身のテキストと写真/動画だけ差し替え
→ 1本40分で完成
```
