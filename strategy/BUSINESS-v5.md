# 🔥 東上リンク — ビジネス戦略 v5

> 「WEBから拾って、ポップに並べて、行きたいを押させて、だれでも広告」

---

## 🎯 核心: 4つの柱

```
1. WEBネタ拾い → 編集して掲載（ユーザー投稿だけじゃない）
2. ポップデザイン → 見てるだけで楽しい
3. 「行きたい」だけ → 迷わせない、考えさせない
4. だれでも広告 → 店舗も企業も個人も、ボタン1つで載せれる
```

## 🙋 「行きたい」だけ

### 理由

| ユーザー行動 | 心理 |
|-------------|------|
| 見る → 「行きたい」を押す | 「いいね」より具体的 |
| 押す → カウントが増える | 承認欲求 + 共感 |
| 押した店がランクイン | 「推し」が上がる喜び |
| 後から「行った」報告 | 完了体験 |

### 行動フロー（超シンプル）

```
見る → 行きたい → おしまい
```

**他は何もいらない。**

- コメント機能 → なし（荒らし防止）
- フォロー機能 → なし（SNSじゃない）
- DM機能 → なし（複雑になる）
- 評価機能 → なし（「行きたい」だけ）

## 📢 だれでも広告

### 仕組み: セルフサービス広告プラットフォーム

```
広告主が自分で申込 → 支払い → 掲載 → 完了
```

### 広告枠

| 枠 | 位置 | 価格 | 効果 |
|----|------|------|------|
| **スポット** | フィード中に1枚混ぜる | ¥1,000/日 | 発見型 |
| **バナー** | ランキングの下 | ¥3,000/週 | 認知型 |
| **プッシュ** | 通知で送信 | ¥5,000/回 | 直接型 |
| **特集** | 「今週の推し店」コーナー | ¥10,000/週 | 権威型 |

### 広告申込フロー

```
1. 広告ページで「出稿する」ボタン
2. 店舗名・URL・文言を入力（30秒）
3. 支払い（クレジットカード / コンビニ）
4. 運営が確認（24時間以内）
5. 掲載開始
```

### 広告カードのデザイン（自然に溶け込む）

```

│  ╭────────────────────────────╮     │

│  ╰────────────────────────────╯     │
│                                      │
```

## 💰 収益計算

### セルフサービス広告の収益試算

| フェーズ | 広告主数 | 単価 | 月収 |
|---------|---------|------|------|
| 開始時 | 5件 | ¥3,000/週 | ¥60,000 |
| 成長期 | 20件 | ¥3,000/週 | ¥240,000 |
| 安定期 | 50件 | ¥3,000/週 | ¥600,000 |

### 広告主のROI（費用対効果）

```
広告費: ¥3,000/週 = ¥12,000/月

効果:
├── 表示: 月間5,000回
├── 「行きたい」: 月間200件
├── 来店转化率: 10% = 20人/月
└── 客単価: ¥1,000 × 20人 = ¥20,000

ROI: ¥20,000 / ¥12,000 = 1.67倍
→ 店舗にとって「元取れる」
```
