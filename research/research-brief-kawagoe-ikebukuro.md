## 🎯 やばい店の定義

```
「知る人ぞ知る、行く価値のある店」

条件:
├── 駅徒歩10分以内
├── SNSフォロワー < 1,000（まだ知られてない）
├── 何か「やばい」がある（味、店主、雰囲気、価格）
└── 実在する（営業中・アクセス可能）
```

### 価格のインパクト例
- 焼き鳥80円
- 枝豆100円
- マグロ寿司300円
- お通し代なし
- 限定メニュー

## 🔍 リサーチ方法

### 1. Google検索（10分/店）
```
「駅名 + カフェ」
「駅名 + 居酒屋」
「駅名 + やばい」
「駅名 + 隠れ家」
```

### 2. Googleマップ（10分/店）
- 店舗名で検索
- 口コミを読む（星4.0以上、件数少ない店を狙う）
- 写真を保存（URL控える）

### 3. Instagram（5分/店）
- 位置情報タグで検索
- 投稿数少ない店 = まだ知られてない証拠

### 4. 食べログ/Retty（5分/店）
- 基本情報確認
- 評価・口コミ

### 5. Threads（5分/店）
- ハッシュタグ検索
- 地元の声を確認

## 🗣️ よくある質問

**Q: チェーン店は含める？**
A: 含めない。個人店・地域密着店のみ。

**Q: 閉店した店は？**
A: 除外。営業中の確認必須。

**Q: 価格が変わっている場合は？**
A: 最新情報を記載。ソースのURLも残す。

**Q: 見つからない駅は？**
A: その駅は「なし」で提出。無理にねじ込まない。
